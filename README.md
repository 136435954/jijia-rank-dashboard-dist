# 积加排名看板 桌面版 使用说明

**版本**：v1.11.0
**更新日期**：2026-10-19

---

## 下载安装

- 安装包：前往本仓库 **Releases** 页下载 `积加排名看板_Setup_<版本号>.exe`（Windows 双击安装，无需任何运行环境）
- 更新：软件启动时会自动检查 Releases 是否有新版本，发现新版会弹出提示

## 一、软件简介

积加排名看板桌面版是一套 Windows 独立软件，双击安装即可使用，无需浏览器、无需安装任何运行环境。

核心功能：
1. **BSR 排名查询**：按 ASIN 查询亚马逊大类目+小类目排名
2. **关键词排名查询**：查看关键词的广告位和自然位
3. **Excel 模板一键填充**：自动填充 BSR、关键词、销售/广告/库存数据

最大优势：**本机出口 IP 固定**，只需把电脑 IP 加入积加开放平台白名单，就不会再出现"无访问权限"的问题。

---

## 二、安装

1. 双击 `积加排名看板_Setup_1.11.0.exe`，按向导选择安装目录
2. 安装完成后桌面和开始菜单会自动生成快捷方式
3. 双击图标打开，**无需安装 Node.js 或任何其他环境**
4. 软件只允许运行一个实例，重复双击会自动退出第二个

---

## 三、配置凭证

首次使用需进入「设置」页，配置以下信息：

1. **积加开放平台 AppID / AppKey**：在积加开放平台后台获取
2. **积加后台 x-auth-token**：从积加后台浏览器请求头中获取

各区块「保存」按钮独立生效。凭证以 AES 加密保存在本机，**加密密钥为软件首次启动时随机生成**（存于本机用户数据目录，不随软件分发），下次启动自动读取，无需重复填写。

如需**清空**某项凭证（如不再使用），把对应输入框内容删空后点「保存」即可清除。

配置完成后可点击「测试连接」验证，按钮下方会显示绿色"测试通过"或红色"测试失败+具体原因"。

### IP 白名单（关键一步）

桌面版请求从本机发出，出口 IP 就是你电脑的 IP。请在积加开放平台"访问API配置"中，把当前电脑的出口 IP 加入白名单。

查询本机出口 IP：访问 https://myip.ipip.net

若提示"XX 无访问权限"，把提示里的 IP 加入白名单即可。

## 四、功能使用

### 4.1 BSR 查询

1. 切换到「BSR 查询」Tab
2. 输入一个或多个 ASIN（逗号或换行分隔）
3. 勾选站点（US/UK 等）
4. 点「查询」查看结果

结果显示大类目+小类目排名，格式如：
```
#22519 in Tools & Home Improvement
#7 in Wire Rope Cutters
```

### 4.2 关键词排名查询

1. 切换到「关键词查询」Tab
2. 输入 ASIN 和站点
3. 点「查询」查看每个关键词的：
   - **广告位**：格式 P页码-位次/每页坑位总数（如 P1-7/12）
   - **自然位**：格式 P页码-位次/每页坑位总数（如 P1-42/48）
   - **最近抓取时间**：已自动转为北京时间，与积加后台一致

没投广告/无自然排名分别显示「无广告位」「无自然位」。

### 4.3 报表填充

1. 切换到「报表填充」Tab
2. **选择销售统计周期**（默认上周日~上周六，可自定义日期范围）
3. 上传每周运营报表模板（.xlsx）
4. 点「开始填充」，等待约1分钟（受积加接口限流影响）
5. 填充完成后点「下载填充后的文件」

软件自动填充以下列：

| 列 | 字段 | 说明 |
|---|---|---|
| E | FBA总入库 | 已发货FBA + 计划入库FBA |
| F | FBA可售 | |
| G | BSR排名 | 大类目+小类目两行 |
| H | 销售净毛利 | |
| I | 退款销售额 | 负数 |
| J | 销售净毛利率 | 小数格式（如 0.2446） |
| K | 广告花费 | 负数 |
| L | 销量 | |
| M | 广告销售额 | |
| N | 销售额 | |
| O | ACOS | 小数格式 |
| P | ACOAS | 小数格式 |
| Q | CTR | 小数格式 |
| R | 广告CVR | 小数格式 |
| T | 广告位 | 按关键词 |
| U | 自然位 | 按关键词 |

填充说明：
- **店铺匹配**：软件按模板「店铺」列精确匹配积加后台店铺，匹配不到的商品行该列留空、**不会误填其他店铺的数据**（v1.11.0 加固）
- 填充完成后界面显示统计：产品数、BSR已填、销售数据已填、关键词已填充、关键词未匹配

## 五、排名显示格式（可自定义）

在「设置」页 →「排名显示格式」可以自定义 BSR 排名的显示格式：

- **默认格式**：`#{rank} in {category}` → `#668 in Tools & Home Improvement`
- **改间距**：输入 `#{rank}   {category}`（多个空格拉开间距）
- **改分隔符**：输入 `#{rank} - {category}`

软件表格和下载的 Excel 都按此格式填充，修改后立即生效。

## 六、凭证与数据存放位置

- 凭证文件：`%APPDATA%\jijia-rank-dashboard-desktop\data\credentials.json`
- 加密密钥文件：`%APPDATA%\jijia-rank-dashboard-desktop\data\.jijia_secret`（首次启动自动生成）

卸载软件后如需彻底清除凭证，可手动删除该目录。

**升级说明**：从旧版本（v1.10.x 及更早）升级到 v1.11.0 后，软件会自动读取旧凭证并迁移到新加密方式，无需重新配置。

## 七、常见问题

| 问题 | 解决方法 |
|---|---|
| 打开后页面空白 / 接口失败 | 检查 3100 端口是否被占用，关闭占用程序后重试 |
| 双击没反应 / 只弹出一个窗口 | 单实例限制属正常，查看任务栏或已打开的窗口 |
| 杀毒软件提示 | exe 未做数字签名，属正常提示，选择"允许"即可 |
| 提示"无访问权限" | 把提示里的 IP 加入积加开放平台白名单 |
| 填充超时 | v1.10.0 已把超时调到180秒，填充约1分钟属正常 |
| 销售数据和积加后台对不上 | 比例字段软件存的是小数（0.2446），积加后台显示24.46%，数值相同 |
| 某商品行留空没填 | 该商品店铺名与积加后台店铺匹配不上（请核对店铺列写法），软件不会误填其他店铺数据 |
| 迁移到新电脑 | 重新安装 exe，重新配置凭证、重新加入新电脑 IP 白名单 |

---

## 八、注意事项

1. 销售数据币种为 USD（积加接口返回美元计价）
2. 比例字段（毛利率/ACOS/CTR/CVR）写入 Excel 为小数格式（如 0.2446），与积加后台显示的 24.46% 数值一致
3. 退款销售额和广告花费为负数
4. 填充耗时约1分钟（积加接口限流5秒/次）
5. 凭证保存在本机，AES 加密，不会上传到任何服务器
6. 软件界面左上角显示当前版本号，与安装包文件名版本一致
