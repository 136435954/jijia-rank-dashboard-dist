**版本**：v1.15.3
**更新日期**：2026-11-09

- 更新：软件启动时会自动检查 Releases 是否有新版本，发现新版会弹出提示

## 软件简介

积加排名看板桌面版是一套 Windows 独立软件，双击安装即可使用，无需浏览器、无需安装任何运行环境。

**核心功能：**

- **BSR 排名查询**：按 ASIN 查询亚马逊大类目+小类目排名
- **关键词排名查询**：查看关键词的广告位和自然位
- **Excel 模板一键填充**：自动填充 BSR、关键词、销售/广告/库存数据

## 1. 这个软件帮你做什么

一句话：输入站点 + ASIN，自动拿到两类排名（BSR 销售排名、关键词广告位/自然位），一键填进你的每周运营报表模板。

两个前提：① 你有积加 ERP 账号并已配置关键词监控（每个站点每个ASIN只能有一组监控）；② 按本文第 2 节完成一次凭证配置（约 10 分钟，之后每周只需偶尔更新 token）。

开始之前，你需要准备三样东西：

| 凭证 / 材料 | 是什么 | 从哪来 |
| --- | --- | --- |
| AppID / AppKey | 积加开放平台应用的鉴权凭证 | 积加开放平台后台「应用管理」创建应用后获取（长期有效，配一次即可）（需要跟客服开通权限） |
| 出口 IP 白名单 | 允许调用开放平台接口的 IP | 在开放平台后台把当前电脑的公网 IP 加入白名单（一次性） |
| x-auth-token（JWT） | 访问关键词数据的登录令牌 | 登录积加后台后，从浏览器 localStorage 提取（需定期更新） |

## 2. 第一步：配置凭证

### 2.1 配置开放平台凭证

1. 打开软件，进入设置页。
2. 在「开放平台凭证」区填入 AppID 与 AppKey，点击保存。
3. 确认积加开放平台后台已创建应用、且当前电脑出口 IP 已加白名单。
4. 保存后该区显示「已配置」即成功；显示「未配置」表示还有一项没填。
5. 完成判断：在首页输入任一真实 ASIN，点「①拉取BSR」能看到该商品的大类/小类排名。

### 2.2 配置后台 token（约 7 天更新一次）

1. 用浏览器打开积加商家后台。
2. 登录后按 F12 打开开发者工具，切到 Application / 应用 面板，左侧选 Local Storage。
3. 找到当前站点域名下的 USER_INFO 键，展开后复制 token 字段的完整值（双引号里面的）。
4. 回到软件设置页，在「积加后台 token」区粘贴该值，点击保存。
5. 保存后该区显示「已配置」即成功。
6. 完成判断：在首页输入真实 ASIN，点「②实时拉关键词」能看到该商品监控组的关键词排名列表。

## 3. 第二步：日常使用（四个功能按钮）

### 3.1 功能① 拉取 BSR（销售排名）

- 站点支持三种模式：①全部站点（默认，不选任何站点）：只填 ASIN，查询该 ASIN 在所有站点的排名数据；②单选：点击一个站点按钮（如「US」），只显示该站点数据；③多选：点击多个站点按钮（如「US」「UK」），显示所选站点数据。可随时点「全部站点」复位回默认。
- 在 ASIN 输入框粘贴一个或多个 ASIN（多个用逗号或换行分隔）。
- 点击「①拉取BSR」。
- 结果区显示每个商品一行：主图、产品名、ASIN、店铺站点、售价、FBA 库存、大类排名、小类排名。其中店铺站点列（如"JUYI美国:US""HAORAN美国:US"）用于区分同一 ASIN 在不同店铺的数据。

### 3.2 功能② 实时拉关键词（广告位 + 自然位）

1. 选择站点，输入一个 ASIN。
2. 点击「②实时拉关键词」。
3. 结果表格按行展示该 ASIN 监控组内的全部关键词：
   - 关键词：监控的关键词文本
   - 最近抓取时间：积加最近一次抓取的时间（已转换为北京时间，与积加后台「最近抓取时间(CN)」口径一致）
   - 广告位（红）：如 P1-2/12 = 第 1 页第 2 位，该页共 12 个广告位；没投广告显示「无广告位」
   - 自然位（绿）：如 P1-9/48 = 第 1 页第 9 位，该页共 48 个自然位

说明：该功能依赖监控组配置。若 ASIN 未加入任何监控组，结果为空，请先在积加后台「广告 → 关键词监控」中把该 ASIN 加进监控组。

### 3.3 功能③ 导入 Excel（兜底）

适用场景：token 过期还没更新、或不想配置 token 时，仍然要查看关键词排名。

1. 在积加后台「关键词监控」模块导出关键词数据 Excel。
2. 点击「③导入Excel」，选择导出的文件。
3. 软件自动识别列（关键词、广告排名、自然排名、抓取时间），按 ASIN 归组展示。

### 3.4 功能④ 上传模板一键填充（最常用）⭐

1. 准备好你的每周运营报表模板（.xlsx，格式见第 4 节）；没有模板时，可在「报表填充」页点标题右侧「下载模板」按钮，保存内置空白模板（21 列 × 402 行、20 个产品位）。
2. 点击「④上传模板一键填充」，选择模板文件。
3. 软件自动遍历每一个产品位（每 20 行一个产品）：
   - 按「站点 + ASIN」拉取并填入「BSR排名」「FBA 库存」「销售 / 广告 / 毛利 / ACOS」等列
   - 按「站点 + ASIN」去积加「关键词监控」取该 ASIN 的全部监控词，按自然排名从好到差填进「关键词」列，并把该词对应的「当前广告位」「当前自然排名位」一并回填
4. 处理完成后自动下载填好的新 Excel，并弹出统计：填了几个 BSR、自动写入几个关键词、几个产品位、另有几个词因行数不够未写入。

说明（v1.15.3 起）：

- **关键词列可以留空**，只需填好店铺 / 产品名称 / SKU / ASIN
- 已经手填的关键词一律保留，软件只补空行，不覆盖、不重复
- 每个产品位固定 20 行，监控词多于 20 个时只写前 20 个（按自然排名），结果里会提示缺口数量
- 店铺名必须能看出站点（如 `JUYI美国`、`JUYI-UK`、`BOOSDEN英国`）；看不出的产品位关键词会留空并提示，不会拿别的站点词硬填

注意：同一「站点 + ASIN」只会查询一次（软件已缓存），同一个 ASIN 出现在多个站点时会分别查询。

## 4. 第三步：模板格式要求（功能④必读）

软件只识别固定的列位置，请确认模板表头与下列布局一致（列号从 0 开始数）：

| 列号 | 表头 | 说明 | 是否要填 |
| --- | --- | --- | --- |
| 0 | 店铺 | 含国家名，如 JUYI美国、BOOSDEN英国 | 手动填 |
| 1 | 产品名称 | — | 手动填 |
| 2 | SKU | — | 手动填 |
| 3 | ASIN | B0 开头 10 位，有值即产品行 | 手动填 |
| 4,5 | FBA总入库 / FBA可售 | — | 手动填（版本1.11.0已更新自动填） |
| 6 | BSR排名 | 软件填，如 #1234 | 自动填 |
| 7~17 | 销售/广告/毛利/ACOS 等 | — | 手动填（版本1.11.0已更新自动填） |
| 18 | 关键词 | 软件按「站点 + ASIN」自动填（v1.15.3）；手填的保留、重复的不重写 | 可留空 / 自动填 |
| 19 | 当前广告位 | 软件填，如 P1-2 | 自动填 |
| 20 | 当前自然排名位 | 软件填，如 P1-9 | 自动填 |

**行判定规则：**

- 产品位：每 20 行一个产品（第 1–18 列纵向合并）；第 3 行起，第 3 列 ASIN 为合法格式（B0 开头 10 位）即识别为一个产品位。
- 站点识别：从店铺名自动识别站点，中文市场名优先（「美国」→ US、「英国」→ UK、「加拿大」→ CA 等 21 站全覆盖），也认 `JUYI-UK`、`JUYI_US`、`JUYI Germany` 这类英文写法；**识别不到时跳过该产品位、不猜站点**（v1.15.3 起，从根上避免同一 ASIN 多站点串词）。
- 同一 ASIN 挂多个站点时，每个站点各占一个 20 行产品位、写不同店铺名，各取各的词，互不影响。
- 模板里站点和 ASIN 随便改，软件每次都会重新读取，不用改软件。

## 5. 常见问题（FAQ）

| 问题 | 怎么办 |
| --- | --- |
| 提示「token 已过期，请重新扫码」 | JWT 约 7 天过期，属正常现象。按第 1 节第 2 步重新提取 token 粘贴即可。 |
| 提示 appKey 不匹配 | AppID 与 AppKey 没有配对。到积加开放平台后台确认复制的两个值来自同一个应用。 |
| 提示白名单 / 无权限 | 当前电脑出口 IP 未在开放平台白名单内。到后台把本机公网 IP 加入白名单。 |
| 功能②结果为空 | 该 ASIN 没有加入任何关键词监控组。先去积加后台「广告 → 关键词监控」添加该 ASIN。 |
| 关键词填不进去（跳过） | 模板里的关键词和监控里的词不一致（文本要完全一致，不区分大小写）。检查监控组里是否有该词。 |
| 显示「无广告位」 | 该关键词当前没投广告，不是错误，跳过即可。 |
| 功能④下载的文件格式变了 | 请确认上传的是 .xlsx 模板且列布局与第 4 节一致；软件会保留原表其他列和格式。 |
| 关键词列没有自动填上 | 先看结果里的提示：①「有 N 个产品位无法识别站点」→ 把店铺名改成带站点的写法（如 `JUYI英国`）；②「未找到监控组」→ 该 ASIN 还没加入积加关键词监控；两者都正常就重填一次 |
| 监控词多于 20 个怎么办 | 每个产品位固定 20 行，只写自然排名前 20 个，结果会提示缺口数量；可精简监控词，或把该 ASIN 再占一个 20 行产品位（同站点同 ASIN 会接着往下填） |

Q：BSR 查询的站点怎么选？支持哪些站点？
A：v1.8.0 起站点选择改为下拉框（可多选）：不选 = 全部站点；点选一个 = 只看该站点；点选多个 = 看这几个站点。站点已扩展为亚马逊 21 个站点：美国、英国、加拿大、德国、法国、意大利、西班牙、日本、墨西哥、澳大利亚、荷兰、瑞典、波兰、土耳其、阿联酋、沙特、印度、新加坡、巴西、比利时、爱尔兰。关键词排名页的站点下拉同步扩展。

## 桌面版（Windows 安装版）⭐

桌面版是积加排名看板在本机运行的独立软件，无需浏览器、无需登录网页端，双击安装即可使用。与云版相比，最大的好处是本机出口 IP 固定：只需把当前电脑的出口 IP 加入积加开放平台白名单，就不会再出现"无访问权限"的问题。

### 1. 安装

1. 双击 `积加排名看板_Setup_1.15.3.exe`，按向导选择安装目录（默认 C:\Program Files\积加排名看板）；
2. 安装完成后桌面与开始菜单会自动生成"积加排名看板"快捷方式；
3. 双击图标即可打开使用，无需安装 Node.js 或任何其他环境。

### 2. 配置凭证

配置方式与网页版完全一致：打开"设置"页，分别填入积加开放平台 AppID / AppKey 与积加后台 x-auth-token，点击"保存"即可。保存后凭证以 AES 加密写入本机文件，下次启动自动读取，无需重复填写。

配置完成后可点击"测试连接"按钮验证，按钮下方会显示绿色"测试通过"或红色"测试失败+具体原因"。

### 3. IP 白名单（关键一步）

桌面版的请求从本机发出，出口 IP 就是你电脑的 IP。请在积加开放平台"访问API配置"中，把当前电脑的出口 IP 加入白名单。查询本机出口 IP 可访问 https://myip.ipip.net 之类的网站查看。若提示"XX 无访问权限"，把提示里的 IP 加入白名单即可（常见错误：IP 少写一位，如把 115.191.4.5 写成 15.191.4.5）。

[查询本机出口 IP 示例（curl cip.cc）]

### 4. 凭证与数据存放位置

凭证文件存放在：%APPDATA%\积加排名看板\data\credentials.json（Windows 用户目录下）。卸载软件后如需彻底清除凭证，可手动删除该目录。

### 5. 常见问题（桌面版补充）

- 打开后页面空白 / 接口失败：检查 3100 端口是否被占用（可关闭占用程序后重试），或退出后重新打开；
- 杀毒软件提示：首次运行可能被安全软件拦截，请选择"允许"，exe 未做数字签名，属正常提示；
- 云版与桌面版可同时使用：两者互不影响，数据都在各自环境内。
- BSR 查询报「参数[marketIdList]类型错误」：已修复（2026-09-23 版本）。旧版本把站点代码当数字 ID 传入导致报错；新版已改为积加要求的签名方式与站点自动识别，重新安装最新安装包即可。
- BSR 查询报「请求签名校验不通过」：已修复。新版已按积加规则自动加签（sign = md5(JSON串+appKey)，header 名 sign），无需手工处理。
- 数据准确性说明：BSR 与关键词排名均为积加开放平台/积加后台实时返回的真实数据；同一 ASIN 在美国站可能出现在多个店铺（如 HAORAN、JUYI），会分别展示。

## 6. 排名显示格式（可自定义）

2026-09-26 版起，BSR 排名的软件显示与 Excel 填充格式均可自定义，用于调整排名数字与类目名之间的间距或分隔符。

- 默认格式：#668 in Tools & Home Improvement（{rank}＝排名数字，{category}＝类目名）
- 在哪里改：软件「设置」页 →「排名显示格式」→ 输入格式模板 → 点击保存
- 改间距：输入「#668   Tools & Home Improvement」（多个空格拉开间距）
- 改分隔符：输入「#668 - Tools & Home Improvement」

注意：软件表格与下载的 Excel 均按该格式填充；默认格式与亚马逊后台展示一致。修改后立即生效并自动保存。
